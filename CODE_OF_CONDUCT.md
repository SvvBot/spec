# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, in every project space: issues, pull requests, discussions, and any event or
channel run for the NOMOS Protocol.

In short: be respectful and constructive, argue about the specification and not the person, and
assume good faith. Harassment of any kind is not tolerated.

Report unacceptable behaviour to **allan@nomosprotocol.com**. Reports are handled in confidence,
and the maintainers will act on them as the Covenant's enforcement guidelines describe.
